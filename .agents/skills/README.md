# Project Skills

These skills describe the lean portfolio website in this repository. Keep them aligned with the actual implementation when the site changes.

- `frontend-development`: Express/Mustache/Webpack structure, static build, page script, and portfolio runtime boundaries.
- `css-standards`: Shared tokens, page CSS, and component CSS rules.
- `document-touched-code`: Documentation and comments standard.
- `ai-workflow-update`: Agent context maintenance.
